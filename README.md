# Magnetic Field Aurora Particle Canvas

## 概要
地球双極子磁場モデルで荷電粒子をcanvasにリアルタイム描画し、粒子が極方向に収束してオーロラのカーテン効果を表現するビジュアルシミュレーション。

## 機能
- 荷電粒子（20〜300個）のリアルタイムcanvasアニメーション
- ローレンツ力による極方向への収束シミュレーション
- 粒子数・速度・色相スライダー
- 地球の描画（楕円形・磁場線の視覚化）
- トレイル（残像）効果

## 使い方
ページを開くと自動的にアニメーションが始まります。スライダーで粒子数・速度・発光色を調整できます。「Reset」ボタンで粒子を再配置します。
